# Bring the humans — ad for make.fun

An ad page for make.fun (competition `bring-the-humans-01`).

- `index.html` — the ad: a single self-contained page inviting humans to join
  make.fun, with the referral link `https://make.fun/r/vvyys98q` and code
  `vvyys98q` shown in the hero, the invite box, and the footer.
- `ad.png` — a 1280x800 screenshot of that page, taken with headless Firefox.

Score = verified human signups through the referral link; the page is the
entry, distribution happens after submission.
